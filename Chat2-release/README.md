# ChatTwo-CN

基于 [ChatTwo](https://github.com/SitiSchu/ChatTwo)（EUPL v1.2 许可）进行中文化及功能改进的 FFXIV 聊天框替换插件，对原生消息栏进行模仿式重制。

## 主要特性

- **中文化**：界面与设置全中文
- **右键菜单**：一级菜单复刻游戏原生菜单（玩家 / 道具 / 装备，菜单项与原生对齐）；"屏蔽机能"二级子菜单为插件自建（加入黑名单 / 加入屏蔽名单 / 记录屏蔽词），点击直接生效，好友仅显示"记录屏蔽词"
- **原生菜单跟手 + 挖洞**：菜单跟随鼠标、边缘自动贴屏；聊天框内容在菜单区域镂空（顶点级挖洞），菜单在聊天框内也能完整显示与点击
- **聊天文字描边**：贴近游戏原生 Axis 字体的细黑描边观感
- **未读消息提示**：高亮 / 呼吸 / 无 三种模式可切换（默认高亮）
- **设置重构**：独立"字体设置"页、"显示时间戳"开关、仿原生界面等
- **兼容其他插件**：支持其他插件（如 Daily Routines、Allagan Tools）的右键菜单项注入与二级菜单显示
- **PopOut 独立窗口**：标签页可弹出为独立窗口，支持独立选字、锁定/关闭快捷按钮

## 已知问题

- **一级菜单为游戏原生菜单，二级菜单为插件自建**：一级菜单渲染读取游戏菜单结构，二级菜单渲染读取节点树——游戏原生二级菜单的内容生成深度绑定完整右键事件流，插件场景无法触发，因此"屏蔽机能"二级菜单为插件自建实现（这也是"无可用指令时显示占位文本"的由来与解法）。
- **部分菜单项无法按目标状态过滤**：游戏对原生菜单项的自动过滤依赖"右键目标内部状态"（由原生右键事件链写入），插件模拟触发时该状态缺失，个别原生项（如"从新人频道移除"）可能不会按目标状态隐藏。
- 其他：原生聊天框的某些行为（如输入法候选框位置、部分原生菜单联动）可能与原版存在差异。

## 构建

```sh
cd ChatTwo
dotnet build -c Release
```

输出：`ChatTwo/bin/Release/ChatTwoCN.dll`
